Introduction

This project was created as part of the Data Communication assignment. The aim of the project was to design and develop a complete web page that summarizes everything studied during the semester in Data Communication. The website was built using HTML, CSS, and JavaScript and was uploaded to GitHub for online access and submission.

The website presents important concepts learned in class, including networking fundamentals, transmission media, signals, wireless technologies, cybersecurity, data protection, and communication systems. It also demonstrates practical web development skills such as navigation menus, hyperlinks, responsive layouts, multimedia integration, and GitHub deployment.

Objectives Of The Project

  • To summarize all topics studied in Data Communication.
  • To create a responsive and attractive website.
  • To include personal information such as name, ID, biography, and image.
  • To create internal navigation using menu tabs.
  • To include external and internal hyperlinks.
  • To add a telegraph communication diagram.
  • To embed a YouTube video inside the web page.
  • To publish the project on GitHub using GitHub Pages.
  • To improve practical web development skills.

Features Of The Website

The completed website contains all required features from the assignment instructions.

1. Personal Information Section

The website includes the student name, student ID, short biography, and personal image. This section introduces the student and explains interests in networking and communication technologies.

2. Navigation Menu

The website contains more than three navigation tabs, including Home, Concepts, Topics, Telegraph, Inspiration, and Resources. These menu items link to sections within the same page using anchor links.

3. Five Or More Sections

  1. Hero/Home Section
  2. Profile Section
  3. Concepts Section
  4. Topic Notes Section
  5. Telegraph Diagram Section
  6. Inspiration Section
  7. Resources Section

Topics Covered

Telegraph Diagram

A telegraph communication diagram was included in the project to demonstrate one of the earliest communication systems. The diagram explains how electrical signals travel between a sender and a receiver through transmission wires.

This section helps connect historical communication systems with modern networking technologies.

Inspiration Section

The website contains a section describing what inspires the student about communication technology. The section explains how communication systems help people access education, business opportunities, emergency services, and information globally.

Hyperlinks And Resources

YouTube Video Link

GitHub Deployment

The website was uploaded to GitHub and published using GitHub Pages.

  1. Create repository named “Data Communication Assignment”.
  2. Upload all project files.
  3. Commit changes.
  4. Enable GitHub Pages.
  5. Copy repository link for submission.

GitHub was used for version control and online hosting.

Challenges Faced

  • Incorrect file paths for CSS and JavaScript.
  • GitHub Pages not loading styles correctly.
  • Case sensitivity issues with folder names.
  • Responsive layout adjustments.
  • Image scaling and positioning.

These issues were solved by correcting folder structures and updating file references.

Lessons Learned

  • Website structure using HTML.
  • Responsive design using CSS.
  • JavaScript interactivity.
  • GitHub repository management.
  • GitHub Pages deployment.
  • Navigation systems using anchor links.
  • Embedding multimedia content.
  • Organizing course materials digitally.

Conclusion

This project successfully met all assignment requirements by creating a fully functional and responsive Data Communication portfolio website. The website summarizes important course concepts while demonstrating practical web development and GitHub deployment skills.

The project also improved understanding of networking technologies, communication systems, and modern web development practices.
